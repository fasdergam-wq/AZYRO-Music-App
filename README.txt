AZYRO PWA — комплект для установки как приложение

Содержимое:
- index.html — приложение AZYRO на базе версии 6
- manifest.webmanifest — название, иконки и параметры установки
- sw.js — кэш оболочки для повторного запуска без сети
- icons/ — иконки приложения

ВАЖНО:
PWA устанавливается только с сайта по HTTPS (или localhost для разработки).
Открытие index.html двойным щелчком на компьютере не включает установку PWA.
Для iPhone нужно открыть HTTPS-адрес в Safari → Поделиться → На экран Домой.
Для Android обычно появляется кнопка «Установить AZYRO» или пункт «Установить приложение».

Это пока веб-приложение/PWA, не готовая публикация в App Store или Google Play.
Музыкальные файлы и данные остаются в локальном хранилище браузера конкретного устройства.
